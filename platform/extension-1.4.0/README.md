# 抖音 AI 合集作者采集

> 文档版本 v1.3.8（正式版）｜ 适用版本 扩展 v1.3.8 ｜ 更新日期 2026-10-28

Chrome 插件：在抖音 **精选 / 搜索 / 播放页 / 采集栏目页** 里收集满足下面这组条件的作者 `sec_uid`：

1. 视频挂载了**合集**
2. 带有作者声明：**内容由AI生成**
3. **内容类型命中白名单、且不撞黑名单**（合集名或昵称归一化后判断）

> 前两条是**采集时的拦截条件**，面板上有勾选框可取消放宽。
> 第 3 条**不在采集时拦截**（当前版本导出全量），它的作用是给搜索词定准星（新增搜索词必须锚定白名单、避开黑名单），真正的类型分级在监控后台复核时做。

示例视频：`https://www.douyin.com/jingxuan?modal_id=7680867175699123471`
对应作者：吃药都要可乐送（雾山精神病院）

## 安装

1. 打开 Chrome，地址栏进入 `chrome://extensions/`
2. 打开右上角 **开发者模式**
3. 点 **加载已解压的扩展程序**
4. 选择本仓库目录（包含 `manifest.json` 的文件夹）

Edge 同样可以：`edge://extensions/`。

## 用法

1. 登录 [抖音精选](https://www.douyin.com/jingxuan) 或搜索页（例如搜「漫剧」）
2. 页面右上角的**内嵌浮层面板**和扩展弹窗（popup）功能已经**完全对齐**，用哪个都行：面板是主入口，弹窗留作备用
3. 点 **开始采集**
4. 点 **自动下滑**：精选/搜索页会持续滚内部列表加载更多；播放页会切下一条
5. 命中的作者会去重保存在本地，可复制 `sec_uid` / 导出 TXT、CSV、JSON / 直接上传

插件只读取你浏览器里抖音页面自己发出的推荐/搜索接口和页面上的声明文案，不会另打签名、也不会把数据上传到别处（除非你主动点「上传」）。

## 当日节奏：起点 · 结束今天 · 上传后自动重置（v1.3.5 起） <!-- ver-ok -->

面板顶部那一行是**当天的工作台账**，三个东西：

`当日起点 2026-10-27 09:27:09（今日 12 个）` —— 起点之后命中的作者才算进「今日 N 个」。
`今日 N` 只统计**起点之后**的作者；起点之前的作者仍在列表里，但不算今天的数。

如果这一行显示 `当日起点 未连接`，说明扩展还没问到当日的真起点（后台没响应或存储没读到）。
这时「今日 N 个」按**本地零点**起算，N 会偏大，「今日 N 个」也不显示在起点行上；点一次「开始采集」或重开弹窗通常就能连上。
跨天时起点不用人工设，自动回落到**今天第一个作者的采集时间**（`firstSeen`）；只有今天一条都没采到，才显示 `00:00:00`。

- **上传成功后，起点自动切到此刻**，不再弹「要不要重置」的询问。
  面板/弹窗里的提示行是 `上传成功：本时段共 137 条，本次提交 92 条（新增 45，服务端已存在 47）。`；
  系统通知是 `本时段共 137 条，本次提交 92 条（…）。起点已切到此刻。`（v1.3.8 起两端量词统一为「条」）。
  两个数不一致，说明这次只传了一部分范围，剩下的还在列表里，切大范围再传一次即可。
- **上传有三种"不成功"的样子，别混**（完整口径见 `使用流程SOP.md` §8.1.2）：

  | 你看到 | 含义 | 怎么办 |
  |---|---|---|
  | `当日起点 未连接` | 没问到起点，今日范围按本地零点算 | 点「开始采集」或重开弹窗重连；这期间导出会额外标注「起点未连接」 |
  | `提交结果尚未确认` | 请求发出去了但没拿到回执，服务端收没收到不知道 | **别换 ID、别改内容**，按原样重试一次（服务端按内容去重）；或先去上传记录表核对当日行数 |
  | `服务端已收下，但本地记账失败` | 服务端已收下，本地记账/切起点失败 | **别连点**，去上传记录表核对当日行数 |

- **下班点「结束今天」**（面板和弹窗都有）：一次清四样 —— ① 清空当天的重置历史 ② 起点重置为此刻 ③ 清空已采集列表 ④ 停止采集。
  点之前会弹确认框，确认后**不能撤销**；已经上传过的数据不受影响。
  日常收工就用它，别用「仅清空列表」——后者只清列表、不动起点。
- **上一次重置**：起点行下面那行小字 `上一次重置：2026-10-27 12:40:34（共 8 个）`，
  点左边的小三角 `▸` 展开当天历史：`12:40:34 · 共 8 个 · 结束今天`。
  历史**最多留 5 条、只留当天**；跨天后旧记录自动消失（不靠定时任务，读取时按日期过滤）。
  上传触发的自动重置**不写历史**——那是系统副作用，不是你的主动动作。

> 1.3.5 起**没有「只重置起点、不清列表」的按钮**了。重置只发生在这两处：上传成功、结束今天。

## 判定规则

- **合集**：接口里的 `mix_info` / `mixInfo`，或页面出现合集入口
- **AI 声明**：文案「内容由AI生成」，或 `aigc_info.aigc_label_type === 1`
  「疑似使用AI」默认**不算**作者声明
- **内容类型**：合集名或昵称命中白名单、且不命中黑名单（见下）

前两条在面板里有对应勾选框，可取消来放宽；**内容类型没有开关**，采集阶段不拦截、导出为全量，类型是否达标由监控后台分级复核判定。

**白名单**（命中任一即通过；已删掉光杆「AI」，避免放过「AI说唱/AI音乐」这类）：

```
漫剧, 短剧, AIGC, 动漫, 动画, 次元, 穿越, 重生, 逆袭, 赘婿, 战神, 系统,
王妃, 豪门, 漫画, 番剧, 小剧场, 剧场, 剧集, 末世, 自制动画
```

**黑名单**（命中任一即排除）：

```
汪汪队, 立大功, 民间故事, 寓言, 动物世界, 怀旧, 童年, 军旅, 科普, 双语, 跟读,
后室, 未解之谜, 领养, 咕嘎, 人生副本, 阅读, 育儿, 儿童, 宝宝, 儿歌, 纪录片,
解说, 混剪, 搬运, 影视解说
```

> 经验：新增搜索词必须避开黑名单词，否则搜到的内容会被直接过滤，等于白跑。

## 随机区间定时刷新（v1.3.2 新增） <!-- ver-ok -->

面板和弹窗里新增「随机刷新（仅采集页生效）」开关，用来替代同事那个「随机刷新控制器.exe」（那个 exe 是对前台窗口盲发 Ctrl+F5，会打到浏览器之外的窗口/应用）。

- **默认区间 180~480 秒**；输入框限 **30~3600 秒**。
- 填 `min > max` 自动交换；填的不是有效数字则保留上一个有效值。
- **只在采集页生效**：精选页（`/jingxuan`）、搜索页、播放页、4 个采集栏目页。不在这些页面就跳过本轮，并累计「跳过 N 次」。
- 刷新前先把数据存盘；刷新后自动续采 + 继续计时。
- 面板底部实时显示：`运行中 · 下次刷新 xx 秒 · 已刷 N 次 · 跳过 N 次`。
- 面板故障自动处理期间会**暂停**随机刷新，处理完自动恢复。

## 每日提醒（v1.3.5 起只剩一条） <!-- ver-ok -->

- **每天 18:00** 系统通知，一条说完三件事：
  「今天累计采集 N 个作者。打开面板 → 上传到 43.165.183.142；上传成功后起点会自动重置。下班前记得点「结束今天」清空列表与历史。」
- **原 18:10 的「该清空采集列表了」提醒已删除**，到点不会再响。
  老设备上已注册的那条定时任务（内部名 `daily-clear-remind`）会在扩展启动时自动注销，不需要手动清。
- 提醒是非阻塞系统通知，关机错过后第二天不补，直接排到当天 18:00。

## 数据上传（两条路）

| 方式 | 操作 | 说明 |
|---|---|---|
| 面板/弹窗直接上传 | 点「上传」按钮 | 直接 POST 到 `http://43.165.183.142/api/file`，**单次上限 10000 行**；需先填「上传人 ID」 |
| 导出 TXT 后上传 | 点「导出 TXT」，再用桌面上的 `douyin_sec_id_upload_tool.exe` | 每行一个 `sec_uid` |

面板里「复制ID」和「TXT」两个按钮导出的内容**完全一致**，只是形式不同（复制进剪贴板 / 存成文件）。

### 上传前会自动比对一次（v1.3.5 起） <!-- ver-ok -->

点「上传到 43.165.183.142」时，扩展先拿**本时段总数 T** 和**当前范围命中数 M** 对一下：

- `D = T − M < 10`：不打扰，直接进确认框 → 提交。
- `D ≥ 10`：弹提示块「本时段共 T 条，本次范围只含 M 条，还有 D 条不在范围内。」，三个按钮：
  - **一起上传（含全部）** —— 范围自动切回「今天 + 时段不限」，再弹一次最终确认；
  - **只传当前范围** —— 就按 M 条提交；
  - **取消** —— 什么都不做。
- **当前范围 0 条**：直接报「当前范围 0 条，本时段共 T 条不在此范围内。」，
  **不提交、不动起点**；想传就点「一起上传（含全部）」。

> 比对提示**没有开关**，也不能关掉；阈值固定 10 条。

## 自动换栏目 / 换搜索词

两者默认关闭，需在面板或弹窗手动开启，用于扩大覆盖、避免内容池收敛。

- **自动换栏目**：在采集栏目页生效。按 **全部 → 二次元 → 小剧场 → 影视** 循环；滚满 **40 次**或连续卡住 3 次触发。
- **自动换搜索词**：在搜索页生效。当前固定词 **300 条**（品类 9 × 题材 24 + 工具 13 × 形态 3 + 扩展池 45），另有「动态词池」最多 **300 条**（从搜索页右侧「相关搜索」被动读取，仅当次会话有效、不落盘）；滚满 **30 次**或连续卡住 3 次触发。
- 换词内置 **5 分钟全局冷却**（跨标签页、跨刷新、跨重启均生效），避免频繁整页刷新导致页面崩溃或触发风控。
- 栏目/搜索词切换进度用 `sessionStorage` 记录，刷新后可继续；关闭标签页后会清空、从头开始。

## 安全 / 防封提示

- 插件只读取浏览器里抖音页面自身发出的请求与文案，不发额外网络请求、不伪造签名；但会**模拟页面交互**（换词、点「筛选/最新发布」、合成滚轮下滑、收割「相关搜索」DOM）。风控归因排查时按「不发额外请求，但会模拟点击/滚动」口径表述。
- 自动下滑间隔可选 **4 / 6 / 8 秒**（默认 4 秒）；实际滑动有抖动：多数落在 **2.4~5.6 秒**，约 15% 概率出现 **12~24 秒**长停顿，降低匀速滑动被风控的概率。
- 脚本遇到以下情况会**自动停/自动刷新**（全部是非阻塞提示：页面浮层 + 系统通知，不用弹窗）：
  - **人机验证** → 自动暂停，人工验证后点「自动下滑」恢复
  - **账号被登出** → 自动停止采集，重登后再开始
  - **搜索过于频繁** → 自动停止采集与换词，稍后重试
  - **连续约 90 秒无响应** → 原地自动刷新并按 **30 秒 / 60 秒 / 2 分 / 5 分** 退避重试，刷新后续采；用尽仍无响应才停下转人工
  - **服务异常 502（整页打不开）** → 整页自动重新加载
  - **约 5 分钟无新作者** → 浮出「取消合集条件 / 保持」选择框
- 多台电脑、多账号分发使用：务必遵守**一台 = 一个账号 + 一个 Chrome 用户（profile）**，避免作者列表串号；并让各台电脑的搜索词起点、滑动间隔略作差异，降低被抖音按行为指纹关联判定为群控的风险。
